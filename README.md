To-Do Task Manager

Жоба туралы - Бұл жоба пайдаланушыларға өз тапсырмаларын басқаруға арналған веб-қосымша болып табылады.
Жобаның мақсаты: PHP және MySQL көмегімен тапсырмаларды қосуға, көруге, өзгертуге және жоюға мүмкіндік беретін сайт жасау.

Қолданылатын технологиялар: HTML, CSS, JavaScript, PHP, MySQL, GitHub
Негізгі мүмкіндіктер: Пайдаланушыны тіркеу, Жүйеге кіру, Тапсырма қосу, Тапсырманы өңдеу және жою, Тапсырмаларды іздеу, Тапсырмаларды санат бойынша сүзу

Дерекқор кестелері: 
users — пайдаланушылар
tasks — тапсырмалар
categories — санаттар

Негізгі беттер:
- Басты бет
- Тіркелу беті
- Кіру беті
- Тапсырмалар беті
- Тапсырма қосу беті
- Тапсырманы өңдеу беті


Студенттің аты-жөні: Сүйінбай Таңжарық

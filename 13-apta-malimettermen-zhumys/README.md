# 13-апта — Мәліметтермен жұмыс

Бұл жоба Node.js және Express.js арқылы сервер жағында:
- өнім атауы бойынша іздеу;
- санат бойынша сүзу;
- дата аралығы бойынша сүзу;
- атауы, бағасы немесе датасы бойынша сұрыптау;
- пагинация (әр бетте 6 өнім) функцияларын көрсетеді.

## Іске қосу

1. Компьютерге Node.js орнатыңыз.
2. Осы папканы VS Code арқылы ашыңыз.
3. VS Code терминалын ашыңыз: **Terminal → New Terminal**.
4. Төмендегі командаларды ретімен орындаңыз:

```bash
npm install
npm start
```

5. Браузерден ашыңыз: http://localhost:3000

Серверді тоқтату үшін терминалда `Ctrl + C` басыңыз.

## API мысалы

`/api/products?search=ноутбук&category=Электроника&sort=price_asc&page=1&limit=6`

API JSON форматында `items`, `total`, `page`, `limit`, `totalPages` қайтарады.

Ескерту: мәліметтер әзірге server.js ішіндегі массивте сақталады. Бұл оқу тапсырмасына арналған демонстрациялық нұсқа; тұрақты дерекқор қолданылмаған.
